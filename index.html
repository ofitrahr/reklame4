Pengaturan

Identitas pengedit

Nama ini dicatat pada setiap perubahan agar terlihat siapa mengubah apa.

Koneksi GitHub

Perubahan disimpan sebagai commit ke repositori Anda. Token hanya tersimpan di peramban perangkat ini dan tidak pernah ikut tersimpan ke dalam data.

Cara membuat token (sekali saja)
  1. Buka github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token. Beri nama bebas, masa berlaku sesuai kebutuhan.
  3. Repository access → Only select repositories, pilih repositori peta ini saja.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Salin token yang muncul, tempel di kolom di atas. Token hanya ditampilkan sekali oleh GitHub.

Jangan bagikan token ini. Siapa pun yang memilikinya dapat mengubah isi repositori tersebut.
